# Tiny Risk

A lightweight TinyManager risk module with probability × impact scoring.

Only the **risk title** is required for fast capture. Probability and impact default to `3/5` and can be refined later.

## Alpha

- Standalone app
- TinyManager module package
- 1–25 risk score
- Low / Medium / High / Critical levels
- Severity sorting
- Open / Mitigated / Closed status
- Optional project and owner links
- TypeScript declarations, tests and CI

Version: `0.1.0-alpha.1`
