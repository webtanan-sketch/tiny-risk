# Tiny Risk — مدیریت ریسک

ماژول سبک TinyManager برای ثبت سریع ریسک و امتیازدهی `احتمال × اثر`.

برای کاهش ورودی مدیر، فقط **عنوان ریسک** اجباری است و احتمال و اثر در ثبت سریع به‌صورت پیش‌فرض `3 از 5` قرار می‌گیرند؛ سپس در صورت نیاز قابل تکمیل‌اند.

## Alpha

- Standalone App
- TinyManager Module package
- Risk score از 1 تا 25
- سطح Low / Medium / High / Critical
- مرتب‌سازی بر اساس شدت
- وضعیت Open / Mitigated / Closed
- اتصال اختیاری به پروژه و مالک ریسک
- TypeScript declarations + tests + CI

نسخه: `0.1.0-alpha.1`
